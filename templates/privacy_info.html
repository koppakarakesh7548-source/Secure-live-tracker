🛡️ Privacy Architecture & Responsible Use

1. Purpose of the Platform

Secure Live Tracker is engineered exclusively as an educational, consent-first cybersecurity and security-awareness platform. Inspired by the transparent mechanics of legitimate enterprise link shorteners and traffic analytics systems, its primary mission is to teach users and organizations how web telemetry functions without violating privacy.

2. Informed Visitor Consent

Unlike covert surveillance or deceptive link disguises, Secure Live Tracker intercepts visits with an explicit, readable Consent Gate. No background data acquisition or hardware interaction occurs prior to user interaction.

Visitors retain full agency: selecting Deny & Continue bypasses all technical logging while seamlessly proceeding to the intended destination.

3. Approximate IP Geolocation Disclaimer

Notice: Geolocation lookups performed by this service are derived purely from public IP subnet registries. This provides only broad, approximate regional estimations (e.g., country, state/province, or general city metro area) and is not precise satellite GPS positioning.

4. Prohibited Data Points

The system is architecturally constrained to prevent the collection or extraction of:

  • Camera, microphone, or precise location sensor feeds.
  • Browser passwords, stored credentials, session cookies, or tokens.
  • Local filesystem paths, documents, or clipboard contents.
  • Keystrokes, private correspondence, or browser extension states.
  • Persistent device fingerprints designed to track individuals across domains.

5. Data Retention & Erasure

Data must not be retained indefinitely. The system provides automated time-based retention pruning (defaulting to 90 days or administrator configured) alongside immediate granular deletion controls for individual records and entire campaigns.
