🛡️ Privacy Principles & Limitations

1. Purpose of the Project

Secure Live Tracker is built to demonstrate ethical cybersecurity practices. It illustrates how link analysis can operate with absolute transparency rather than deceitful techniques.

2. Information Collected After Explicit Consent

Only if the visitor clicks Allow & Continue, the system processes: request IP address, approximate country/region/city derived from IP, browser name, operating system, screen dimensions, language, timezone, and visit timestamp.

3. Information NEVER Collected

Zero collection of passwords, authentication tokens, cookies, browsing history, keystrokes, clipboard data, files, browser extensions, or covert hardware/canvas fingerprints.

4. IP Geolocation Limitations

All geolocation results are strictly labeled: "Approximate location based on IP. This is not precise GPS location." IP lookups provide only wide geographic approximations and cannot pinpoint a specific physical address.

5. Visitor Choice Guarantee

Visitors who choose Deny & Continue are never penalized. Zero optional technical data is logged, and they proceed immediately to the original destination URL.
